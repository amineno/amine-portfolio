# Cyberride

Cyberride is a premium e-commerce platform for futuristic LED motorcycle backpacks, featuring real-time customization, cash-on-delivery checkout, and an admin management dashboard.

## Features
- **3D Interactive Product Viewer**: High-fidelity hardshell model with customizable LED matrix presets.
- **E-Commerce Storefront**: Product showcase, cart management, and seamless checkout flow.
- **Admin Portal**: Order management, analytics, and store configuration.
- **Backend Service**: Express.js REST API with Prisma ORM / PostgreSQL integration.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Lucide Icons, Three.js / Canvas
- **Backend**: Node.js, Express, Prisma

## Getting Started

### Installation
```bash
npm install
```

### Running Development Server
```bash
# Start frontend & backend
npm run dev
```
